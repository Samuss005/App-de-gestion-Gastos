# 💰 Control de Gastos Personales

Aplicación Android desarrollada en Java para el registro y control de gastos personales diarios.

![Java](https://img.shields.io/badge/Java-17-blue)
![Android](https://img.shields.io/badge/Android-API_24+-green)
![Android Studio](https://img.shields.io/badge/Android_Studio-2023-purple)

## 📱 Descripción

**Control de Gastos Personales** es una aplicación móvil que ayuda a los usuarios a registrar, organizar y visualizar sus gastos diarios de manera sencilla. Permite agregar gastos con descripción, monto, categoría y fecha, y obtener un resumen visual del gasto total desglosado por categoría.

Esta app fue desarrollada como parte de la actividad **"Crea tu App con IA"**, utilizando Inteligencia Artificial como asistente de programación.

## ✨ Características

- ✅ **Agregar gastos** con descripción, monto, categoría y fecha
- ✅ **5 categorías** disponibles: Comida 🍔, Transporte 🚗, Entretenimiento 🎬, Servicios 💡, Otros 📦
- ✅ **Lista de gastos** con RecyclerView para visualización eficiente
- ✅ **Eliminar gastos** con confirmación para evitar borrados accidentales
- ✅ **Total en tiempo real** que se actualiza automáticamente
- ✅ **Pantalla de resumen** con desglose por categoría y barras de progreso
- ✅ **Porcentajes** de gasto por categoría
- ✅ **Diseño Material Design** moderno y limpio
- ✅ **Validaciones** de campos para evitar errores


## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java
- **IDE:** Android Studio
- **SDK Mínimo:** API 24 (Android 7.0)
- **Librerías:**
  - AndroidX AppCompat
  - Material Components
  - RecyclerView
  - CardView
